## Audio File Database Structure

Based on the repertoire page, here's a suggested database schema:

### Songs Table

- id
- title
- category (current/past)
- composer
- arrangement
- notes
- external_links (Jim's app, etc.)
- created_at
- updated_at

### Audio Files Table

- id
- song_id (foreign key)
- vocal_part (enum: Sop1, Sop2, Alto1, Alto2, Tenor, Bass, etc.)
- file_url
- file_type (mp3, m4a)
- purpose (practice, pronunciation, tutti)
- created_at

### Additional Resources

- Pronunciation guides
- Sheet music PDFs
- Video recordings
